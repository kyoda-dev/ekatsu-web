# e活 生成AI ショート動画CM プロンプト（8秒・ワンカット・音声あり）

縦型9:16／8秒／カット割りなし。**映像と音声を一度に生成する**構成です。
Veo 3 や Sora 2 系のモデルは、ナレーション・環境音・BGMを映像と一緒に出力できます。
（Kling など音声非対応のモデルの場合は「4. 無音で作る場合」を使ってください）

---

## 1. 本命プロンプト（コピペ用）

```
縦型9:16、8秒、カット割りなしのワンショット。

【映像】
暗い部屋の配信卓。モニターの光だけが、キーボードと手元を照らしている。
カメラはモニターに向かって、途切れず非常にゆっくり前進するだけ。
最後は画面中央に余白を残して静止する。
シネマティックな実写風、浅い被写界深度、自然な粒状感、
青とオフホワイトを基調にした静かで誠実なトーン。
人物の顔ははっきり写さず、手元とシルエットのみ。
画面内に文字・ロゴ・字幕は一切入れない。

【音声】
男性のナレーション（30代、落ち着いた低め、静かに語りかけるトーン、日本語）：
「大きな大会だけが、eスポーツじゃない。」
（少し間を置いて）
「その熱量を、支えたい。」

環境音：遠くのキーボードのタイプ音、かすかな話し声、静かな室内の空気感。
BGM：ごく小さな音量のピアノ。単音でゆっくり。ナレーションを邪魔しない。
```

**ネガティブプロンプト**

```
字幕, 焼き付いた文字, テロップ, ロゴ, ウォーターマーク,
カット割り, シーン転換, 場面切り替え, ズーム, 回り込み, 早いカメラワーク,
崩れた指, 歪んだ顔, 過度な彩度, 安っぽいCG, 大きなBGM, 音割れ
```

> **注意**：セリフを書くと、モデルが勝手に字幕を焼き付けることがあります。
> ネガティブの `字幕, 焼き付いた文字` は必ず入れてください。

---

## 2. ナレーションの尺の目安

8秒に入る日本語は **合計30〜35文字程度**（間を含む）。上のセリフで約7秒、最後に1秒の余白です。
差し替える場合は、この文字数を超えないようにしてください。

| 案 | セリフ | 文字数 |
|---|---|---|
| A（採用） | 大きな大会だけが、eスポーツじゃない。／ その熱量を、支えたい。 | 29 |
| B | 小さな大会にも、本気の熱量がある。／ その火を、絶やさない。 | 27 |
| C | 地方から、eスポーツを支える人たちがいます。 | 21 |

---

## 3. 締めのテロップ（後から重ねる）

映像はワンカットのまま、最後の2秒に文字だけをフェードイン。

```
e活
eスポーツに社会的意義を
@e_ekatsu
```

ロゴは `assets/img/logo.webp` を使用。生成AIには文字を作らせず、編集ソフトで重ねます。

---

## 4. 無音で作る場合（音声非対応モデル）

「1. 本命プロンプト」から **【音声】ブロックをまるごと削除**して生成し、
ナレーションは読み上げAI（TTS）で別録りして重ねます。読み上げ原稿はこちら。

```
大きな大会だけが、eスポーツじゃない。
その熱量を、支えたい。
```

日本語ナレーションは、生成AIに任せるより**TTSで別録りした方が発音とタイミングが安定します**。
映像の出来を優先するなら、こちらの作り方が確実です。

---

## 5. 使うときのコツ

- **顔と指はAIが崩しやすい**ので、手元とシルエット中心の指示にしています。
- 8秒で動きを詰め込むと破綻するため、カメラは「ゆっくり前進するだけ」に固定しています。
- 場面が勝手に切り替わる場合は、冒頭の `カット割りなしのワンショット` を繰り返し書くと安定します。
- 実際の大会映像があるなら、この8秒の前に実素材を3秒足して合計11秒にすると説得力が出ます。
