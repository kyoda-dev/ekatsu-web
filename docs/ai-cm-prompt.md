# e活 生成AI ショート動画CM プロンプト

縦型9:16・15秒想定。Sora / Veo / Kling などの動画生成AIにそのまま貼って使えます。
1カット5〜8秒までのモデルが多いので、**カットごとに生成して繋ぐ**のがおすすめです。

---

## 1. まるごと1本（コピペ用・15秒）

```
縦型9:16、15秒のブランドCM。テーマは「地方 × eスポーツ × VTuber」。
シネマティックな実写風、浅い被写界深度、自然光、落ち着いたコントラスト、
青とオフホワイトを基調にした静かで誠実なトーン。カメラはゆっくりとした
ドリーインとパン。BGMは静かなピアノから始まり、後半でやわらかく盛り上がる。

構成：
(1) 早朝の長野の山並みに朝もやがかかる俯瞰。ゆっくり手前へドリー。
(2) 地方の小さな公民館やゲーミングスペースで、数人がモニターを囲んで
    ゲーム大会をしている。歓声、ハイタッチ、真剣な横顔。手持ち風の微かな揺れ。
(3) 配信卓のモニターにコメントが流れ、キーボードとマウスに光が反射する接写。
(4) 山並みの引き画に戻り、画面中央に余白を残して静かに終わる。

人物の顔ははっきり写さず、手元・後ろ姿・シルエット中心。
画面内に文字やロゴは入れない（テロップは後から重ねる）。
```

**ネガティブプロンプト**

```

```

## 3. ナレーション（読み上げAI用・約15秒）

```
大きな大会だけが、eスポーツじゃない。
仲間内で開く、小さな大会にも、本気の熱量があります。
その熱量に、企業の協賛とVTuberの発信を。
地方 × eスポーツ × VTuber ── e活。
```

## 4. VTuber出演バージョン（差し替え用カット）

パートナーVTuberの立ち絵を使う場合は、カット3を下記に差し替えます。
（キャラクターはAI生成せず、既存の立ち絵を編集ソフトで重ねる前提）

```
配信画面レイアウトの背景素材。9:16縦型、右下と上部に人物用の空きスペース。
淡いグラデーション、細いラインのモーショングラフィック、青とオフホワイト、
ゆっくり流れるパーティクル。ループ可能。文字なし。
```

## 5. 使うときのコツ

- **顔と指はAIが崩しやすい**ので、手元・後ろ姿・シルエット中心の指示にしています。
- **文字は生成させない**。テロップとロゴは後から編集ソフトで重ねる方が確実です。
- 尺が余ったら、末尾に `assets/img/logo.webp` のロゴと `@e_ekatsu` を3秒入れると締まります。
- 実際の大会映像がある場合は、カット2をAI生成ではなく実素材に差し替えると説得力が上がります。
