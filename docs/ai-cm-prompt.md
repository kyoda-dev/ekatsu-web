# e活 生成AI ショート動画CM プロンプト

縦型9:16・約15秒。**カット割りをせず、ワンカット（1ショット）で完結**させる構成です。
カットを繋がないので、生成 → テロップを重ねる、だけで1本になります。

---

## 1. 本命：ワンカット完結（コピペ用）

```
縦型9:16、15秒、カット割りなしのワンショット。
地方の小さなゲーミングスペースの中を、カメラが途切れず一続きに進んでいく。

窓の外に朝もやの山並みが見えるところから始まり、カメラはゆっくり室内へ入る。
数人がモニターを囲んでゲーム大会をしている横を、一定の速度で静かに通り過ぎる。
歓声、身を乗り出す背中、握られたマウス。最後は配信卓のモニターの光の前で
ゆっくり止まり、画面中央に余白を残したまま静止する。

シネマティックな実写風。自然光と暖色の室内光。浅い被写界深度。
青とオフホワイトを基調にした、静かで誠実なトーン。
カメラは滑らかなスライダー移動のみ。カットの切り替え・ズームイン・回り込みはしない。
人物の顔ははっきり写さず、手元・後ろ姿・シルエット中心。
画面内に文字やロゴは入れない。
```

**ネガティブプロンプト**

```
カット割り, シーン転換, 場面切り替え, 早いカメラワーク, ズーム, 回り込み,
文字, ロゴ, 字幕, ウォーターマーク, 崩れた指, 歪んだ顔, 過度な彩度,
安っぽいCG, 大規模アリーナ, 派手なレーザー演出, 手ブレしすぎ
```

> **ポイント**：`ワンショット` `カット割りなし` `カメラは一続き` を必ず書く。
> 書かないと生成AIは勝手に場面を切り替えます。

## 3. ナレーション（読み上げAI用・約15秒）

```
大きな大会だけが、eスポーツじゃない。
仲間内で開く、小さな大会にも、本気の熱量があります。
その熱量に、企業の協賛とVTuberの発信を。
地方 × eスポーツ × VTuber ── e活。
```

## 4. さらに短くしたいとき（8秒・ワンカット）

```
縦型9:16、8秒、カット割りなしのワンショット。
暗い部屋の配信卓。モニターの光だけが手元とキーボードを照らしている。
カメラはモニターに向かって、途切れず非常にゆっくり前進するだけ。
最後は画面中央に余白を残して静止する。
シネマティックな実写風、浅い被写界深度、青とオフホワイト、文字は入れない。
```

テロップは「eスポーツに社会的意義を ／ e活」の1枚だけ。

---

## 5. 使うときのコツ

- **顔と指はAIが崩しやすい**ので、手元・後ろ姿・シルエット中心の指示にしています。
- **文字は生成させない**。テロップとロゴは後から編集ソフトで重ねる方が確実です。
- 生成が場面を切り替えてしまったら、プロンプト冒頭の `カット割りなしのワンショット` を
  さらに強調するか、動きの少ない「4. 8秒版」に切り替えると安定します。
- 末尾に `assets/img/logo.webp` のロゴと `@e_ekatsu` を重ねると締まります。
